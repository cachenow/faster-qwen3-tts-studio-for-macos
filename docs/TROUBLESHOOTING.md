# 排查问题

| 现象 | 检查 |
| --- | --- |
| Windows 启动后显示开发模拟 | 测试音与历史会保留 Mock 标记。生成真实语音需要 macOS ARM64 打包版本。 |
| 模型下载中断 | 在模型管理对相同量化版本选择“下载或继续”。检查剩余空间与网络，下载完整后会校验 SHA-256。 |
| 模型已安装但生成失败 | 记录模型、量化、请求模式、macOS 版本和应用版本。查看后端日志及系统诊断，确认原生库与 MTL0 设备可用。 |
| 麦克风权限被拒绝 | 在系统设置的隐私与安全性中检查麦克风权限，也可上传 PCM WAV。 |
| App 在健康检查前失败 | 参考启动窗口给出的日志位置，提供 BUILD-REPORT.txt 及近期 backend.log 的相关错误。 |
| 系统提示签名或架构有问题 | 确认下载的文件与 SHA256SUMS.txt 一致并来自同一次构建。在 CI 检查签名验证、Mach-O 报告及启动测试。 |

对外分享日志前检查个人目录、文件名及输入内容。应用设置中的系统诊断导出只包含系统和运行时信息。
