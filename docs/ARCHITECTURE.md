# 架构

桌面启动时创建用户数据目录。Rust 启动随 App 打包的 Python，在专属进程组运行并通过启动管道取得端口和会话凭据。Rust 验证健康响应后加载同源 Web 界面。正常退出会关闭进程组，Python 监控父进程以清理异常退出。Windows 使用同一前端，并由开发者显式启动模拟模式。

FastAPI 在内核分配的 loopback 端口监听。API 验证 Host、Origin 和会话凭据。参考文件由服务器分配 UUID，模型文件从允许的模型和量化组合导出固定名称。SQLite 保存历史和音色元数据，WAV 与权重存放在各自目录。

生成请求单独启动推理进程。前端通过 NDJSON 读取 PCM 并使用 Web Audio 调度播放。后端写临时 WAV，收到正常完成标志后提交文件和历史。取消会终止工作进程并清理未完成的文件。合并和 ZIP 导出使用后端临时文件，返回后删除。

macOS 构建先准备前端和独立 Python。依赖连同 Metal wheel 装到可随 App 移动的 Python 目录中。脚本逐个检查 Mach-O、签名，再签名外层 App。DMG 挂载后再次校验完整性并启动 App 检查后端健康。模型权重由应用按需下载。
